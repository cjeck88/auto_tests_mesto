# Тест на создание карточки изображение в Яндекс.Место при помощью автоттеста Selenium.
- Авторизоваться на сайте.
- Создать карт карточку места.
- Проверить изменение количества карточек после создания.
- Удалить созданную карточку.
- Проверить изменение количества карточек после удаления.

# Структура проекта.
- auro_test_create_picture:
    - practice_exercise_test_2.py # Тест
    - README.md # Документация проекта
    - .gitignore # Исключения
    
# Запуск тестов.
- Запуск теста выполняется командой pytest
- pytest test_practice_exercise_2 -v

# Типы тестирования.
- Позитивное автотестирование 

# Что проверяет тест
- создание карточки и ее удаление

# Рекомендации.
- Использовать актуальный URL Яндекс.Место
- Для запуска тестов должны быть установлены пакеты pytest, requests
